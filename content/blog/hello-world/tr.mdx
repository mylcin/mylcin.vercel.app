## Terminal Komutları

Bu blogu konsoldan da gezebilirsin. `⌘K`'ye (ya da `Ctrl K`'ye veya üst menüdeki konsol düğmesine) bas ve şunları dene:

```bash
cd ~/blog              # bloga git
ls -l                  # tüm yazıları listele
cat hello-world/tr.md  # bu yazıyı yazdır
grep security          # yazılarda ve projelerde ara
```
